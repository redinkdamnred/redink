# เว็บเช็คสถานะเซิร์ฟ Minecraft + Discord

เว็บจริงที่ติดต่อเซิร์ฟมายคราฟโดยตรง (Server List Ping) ทุก 30 วินาที แล้วแสดงสถานะ ผู้เล่น เวอร์ชัน ping และประวัติ 24 ชม. พร้อมแจ้งเตือนเข้า Discord

## ทำอะไรได้บ้าง
- เช็คสถานะ **เปิด/ปิดจริง** ของเซิร์ฟ Java หรือ Bedrock
- แสดงจำนวนผู้เล่นและชื่อผู้เล่น (ถ้าเซิร์ฟส่งรายชื่อมา)
- กราฟย้อนหลัง 24 ชม. และเปอร์เซ็นต์ออนไลน์
- กราฟจำนวนผู้เล่นทุกครึ่งชั่วโมง พร้อมสถิติคนเล่นสูงสุด (24 ชม. และตลอดกาล)
- หัวสกินข้างชื่อผู้เล่น (จาก mc-heads.net) และปุ่มสลับโหมดมืด/สว่าง (จำค่าไว้ในเบราว์เซอร์)
- ปุ่ม "แจ้งเตือนเมื่อเซิร์ฟเปิด" ในเบราว์เซอร์ (ต้องเปิดหน้าเว็บค้างไว้ ครั้งเดียวต่อการกดเปิด)
- แสดงจำนวนคนออนไลน์ในเซิร์ฟ Discord บนปุ่มเข้า Discord (ดึงจากลิงก์เชิญ `DISCORD_INVITE` ไม่ต้องเปิด widget)
- ลิงก์เว็บที่แปะใน Discord/LINE ขึ้นการ์ดสถานะปัจจุบัน (Open Graph) และมีป้ายสถานะ SVG ที่ `/badge.svg`
- หน้าแอดมิน `/admin.html` แก้ตารางเวลาและข้อความประกาศผ่านเว็บ (ต้องตั้ง `ADMIN_PASSWORD`)
- Discord webhook: แจ้งในห้องเมื่อเซิร์ฟ **เปิด/ปิด** (แท็ก role ได้) และแจ้งเมื่อมีคนเข้า/ออกเกม (เลือกเปิดได้)
- ปุ่ม "ขอให้เปิดเซิร์ฟ" บนเว็บ: เพื่อนกดแล้วระบบแท็กแอดมินใน Discord (จำกัดอัตรา กันสแปม)
- บอท Discord: คำสั่ง `/status` `/players` `/schedule` `/request` และสถานะบอทแสดงจำนวนคนเล่น
- ปุ่มเข้า Discord ของกลุ่มบนเว็บ
- แชทกลุ่มบนหน้าเว็บ (ข้อความขึ้นสด, ตั้งรหัสผ่านกลุ่มได้, แอดมินลบข้อความ/บล็อกคนได้)

## ติดตั้งบนเครื่องตัวเอง
ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
cp .env.example .env     # แล้วแก้ค่าใน .env
npm start
```
เปิด http://localhost:3000

### ค่าสำคัญใน `.env`
| ค่า | ความหมาย |
|---|---|
| `MC_HOST`, `MC_PORT` | ที่อยู่เซิร์ฟมายคราฟที่จะเช็ค |
| `MC_TYPE` | `java` หรือ `bedrock` |
| `SERVER_NAME`, `PUBLIC_ADDRESS` | ชื่อและที่อยู่ที่โชว์บนเว็บ |
| `ADMIN_PASSWORD` | รหัสผ่านหน้า `/admin.html` ไม่ตั้ง = ปิดหน้าแอดมิน |
| `PUBLIC_URL` | ที่อยู่เว็บจริง ใช้ในการ์ดตัวอย่างลิงก์ (ไม่บังคับ) |

ฝั่งเซิร์ฟมายคราฟต้องมี `enable-status=true` ใน `server.properties` (ค่าเริ่มต้นเปิดอยู่แล้ว) และเว็บต้องเข้าถึงพอร์ตเซิร์ฟได้ ถ้าเซิร์ฟอยู่ที่บ้าน ต้องเปิดพอร์ตหรือใช้ที่อยู่ที่เพื่อนเข้าได้อยู่แล้ว

แก้ตารางที่มักเปิดได้สองทาง: ผ่านหน้าแอดมิน (แนะนำ) หรือแก้ไฟล์ `schedule.json` เป็นค่าตั้งต้น
เมื่อบันทึกจากหน้าแอดมินแล้ว ค่าจะถูกเก็บใน `data/settings.json` และใช้แทน `schedule.json`

## เชื่อม Discord

### แบบง่ายสุด: Webhook (แนะนำเริ่มจากอันนี้)
1. ใน Discord เข้า **ตั้งค่าห้อง → การผสานรวม → เว็บฮุค → สร้างเว็บฮุคใหม่**
2. คัดลอก URL ไปใส่ `DISCORD_WEBHOOK_URL`
3. (ไม่บังคับ) ใส่ `DISCORD_NOTIFY_ROLE_ID` = ID ของ role ที่จะแท็กตอนเปิด/ปิด และ `DISCORD_ADMIN_USER_ID` = ID ของคุณ (เปิด Developer Mode ใน Discord แล้วคลิกขวา → Copy ID)
4. ใส่ `DISCORD_INVITE` เป็นลิงก์เชิญเข้าเซิร์ฟ Discord เพื่อให้มีปุ่มบนเว็บ

### บอท (คำสั่ง /status)
1. ไปที่ https://discord.com/developers/applications → New Application → แท็บ **Bot** → Reset Token → คัดลอกไปใส่ `DISCORD_BOT_TOKEN`
2. แท็บ **OAuth2 → URL Generator** เลือก scope `bot` และ `applications.commands` แล้วเปิดลิงก์ที่ได้เพื่อเชิญบอทเข้าเซิร์ฟ
3. ไม่ต้องเปิด Privileged Intents
4. รันเว็บใหม่ พิมพ์ `/` ใน Discord จะเห็นคำสั่ง `/status` `/players` `/schedule` `/request` (อาจใช้เวลาไม่กี่นาทีถึงขึ้น)

**อย่าเอา token หรือ webhook URL ไปโพสต์สาธารณะ** ถ้าหลุดให้ Reset/ลบแล้วสร้างใหม่ทันที

## อันดับผู้เล่น
หน้าแรกมีตารางอันดับ 5 หมวด: ขุดแร่, ฆ่ามอนสเตอร์, เวลาเล่น, ตายมากสุด, เดินทางไกลสุด (10 อันดับแรกของแต่ละหมวด) ข้อมูลมาจากไฟล์สถิติที่ Minecraft บันทึกเอง (`<โลก>/stats/<uuid>.json`) เว็บดึงผ่าน SFTP ทุก 10 นาที

**ชี้ที่ผู้เล่น = ดูรายละเอียดของหมวดที่เลือกอยู่** (บนมือถือแตะที่แถว) แยกกันชัดเจน ไม่ปนกัน:
- ขุดบล็อก: รวมเป็นหมวด เช่น ไม้ (ทุกชนิดไม้ ทั้งท่อน แผ่น บันได ฯลฯ), หิน (หิน ดีปสเลต หินกรวด ...), ดิน/หญ้า, ทราย/กรวด, แร่, ใบไม้, พืช/ดอกไม้ ฯลฯ
- ขุดแร่: แยกรายชนิด (แร่ดีปสเลตรวมกับแร่ปกติ เช่น ถ่านหิน + ถ่านหินดีปสเลต)
- ฆ่ามอนสเตอร์: แยกรายตัว (ซอมบี้ ครีปเปอร์ ...)
- ตายมากสุด: ถูกมอนสเตอร์ตัวไหนฆ่ากี่ครั้ง ส่วนที่เหลือ (ตกที่สูง ไฟ ลาวา ฯลฯ) รวมเป็น "สาเหตุอื่น" เพราะ Minecraft ไม่เก็บสถิติแยกสาเหตุเหล่านี้
- เวลาเล่น: เวลาที่เล่น / ย่อตัว / นับจากตายและนอนครั้งล่าสุด
- เดินทางไกลสุด: แยกตามวิธี (เดิน วิ่ง ว่ายน้ำ เรือ ม้า ...)

บล็อกที่ไม่รู้จักจะไปอยู่หมวด "อื่น ๆ" ปรับกฎจัดหมวดได้ที่ฟังก์ชัน `blockCat` ใน `ranking.js` และชื่อภาษาไทยใน `public/ranking-client.js` (หลังอัปเดตโค้ดให้รอซิงก์ครั้งถัดไป หรือกด "ดึงข้อมูลตอนนี้" ที่หน้าแอดมิน เพื่อให้รายละเอียดขึ้น)

**ตั้งค่า**
1. ในแผงควบคุมเซิร์ฟ เปิดหน้า Settings > "SFTP Connection Info" จะเห็น Server Address (ที่อยู่กับพอร์ต), Username และ Password
2. ใส่ใน `.env`: `SFTP_HOST` (ที่อยู่ ไม่ต้องมี `sftp://`), `SFTP_PORT`, `SFTP_USER`, `SFTP_PASSWORD`
3. ถ้าชื่อโฟลเดอร์โลกไม่ใช่ `world` ให้ตั้ง `STATS_WORLD_DIR` (ดูที่ `level-name` ใน `server.properties`)
4. รัน `npm install` (หรือ build Docker ใหม่) เพราะมีแพ็กเกจใหม่ `ssh2-sftp-client` แล้วรีสตาร์ทเว็บ
5. เปิดหน้า `/admin.html` ดูส่วน "อันดับผู้เล่น" กด "ดึงข้อมูลตอนนี้" ถ้าไม่สำเร็จจะบอกสาเหตุ

**ควรรู้**
- รหัส SFTP ของแผงแบบ Pterodactyl คือรหัสบัญชีที่ล็อกอินแผง แนะนำให้สร้างผู้ใช้ย่อย (Subuser) ที่ให้สิทธิ์เฉพาะอ่านไฟล์ แล้วใช้บัญชีนั้นกับเว็บ เพื่อไม่ต้องเอารหัสบัญชีหลักมาใส่ใน `.env`
- "เดินทางไกลสุด" รวมระยะทุกวิธี (เดิน วิ่ง ว่ายน้ำ บิน ม้า เรือ รถราง ฯลฯ) ไม่รวมการตกจากที่สูงและการปีนป่าย
- นับ "ขุดแร่" จากบล็อกที่ id ลงท้าย `_ore` และ `ancient_debris` แร่ของม็อดที่ชื่อไม่ตรงรูปแบบ เพิ่มได้ที่ `STATS_EXTRA_ORES`
- ชื่อผู้เล่นมาจาก `usercache.json` ซึ่งเซิร์ฟลบรายชื่อที่ไม่ได้เข้าเล่นเกิน 30 วัน คนที่หายไปนานอาจแสดงเป็น "ผู้เล่น xxxx" โดยไม่มีรูปหัว
- ตัวเลขอัปเดตตามที่เซิร์ฟบันทึกสถิติลงไฟล์ (ราว 5 นาที และตอนผู้เล่นออกจากเกม) จึงช้ากว่าเรียลไทม์เล็กน้อย
- ทุกคนที่เปิดเว็บเห็นอันดับได้ แสดงเฉพาะชื่อและตัวเลข ไม่แสดง uuid
- ทดสอบโดยไม่ต้องใช้ SFTP ได้ด้วย `STATS_LOCAL_DIR=<โฟลเดอร์ที่มี world/stats และ usercache.json>`

## แจ้งเตือนคนเข้า/ออกเซิร์ฟผ่าน Discord
ตั้ง `NOTIFY_PLAYERS=true` ใน `.env` (ต้องมี `DISCORD_WEBHOOK_URL`) แล้วรีสตาร์ทเว็บ เว็บเช็กเซิร์ฟทุก 30 วินาที (ปรับได้ที่ `POLL_SECONDS`) แล้วส่งเข้าห้อง Discord เช่น `🟢 Steve_123 เข้าเกม (3/20)` หรือ `⚪ Alex ออกจากเกม (2/20)`

- ข้อความแจ้งเตือนแบบมีชื่อจะเป็นการ์ดพร้อมหัวสกินของผู้เล่น (ดึงจาก mc-heads.net) ปิดได้ด้วย `NOTIFY_SKIN=false` จะกลับเป็นข้อความธรรมดา
- เซิร์ฟ Minecraft Java ส่งรายชื่อผู้เล่นมาให้เว็บแค่ "ตัวอย่าง" (ปกติไม่เกิน 12 ชื่อ บางเซิร์ฟซ่อนทั้งหมด) ถ้ารายชื่อไม่ครบ เว็บจะแจ้งแค่ `🟢 มีผู้เล่นเข้าเกม (15/20)` โดยไม่ระบุชื่อ แทนการเดาชื่อผิด
- คนที่เข้าแล้วออกภายในรอบเช็กเดียว (ไม่ถึง 30 วินาที) จะไม่ถูกแจ้ง
- รอบแรกหลังเปิดเว็บใช้เป็นฐานเทียบ จะไม่แจ้ง

## แชทบนเว็บ
โค้ดแชทแยกอยู่ใน `chat.js` (ฝั่งเซิร์ฟเวอร์) และ `public/chat-client.js` (หน้าเว็บ) ใช้งานได้ทันทีโดยไม่ต้องติดตั้งแพ็กเกจเพิ่ม

| ค่าใน `.env` | ความหมาย |
|---|---|
| `CHAT_ENABLED` | `true` (ค่าเริ่มต้น) เปิดแชท / `false` ปิดแชททั้งระบบ |
| `CHAT_PASSWORD` | รหัสผ่านของกลุ่ม เพื่อนต้องใส่ก่อนเข้าแชท ไม่ตั้ง = ใครเปิดเว็บก็แชทได้ |
| `CHAT_TO_DISCORD` | `true` = ส่งข้อความแชทไปห้อง Discord ผ่าน `DISCORD_WEBHOOK_URL` (ทางเดียว) ค่าเริ่มต้น `false` |
| `CHAT_HISTORY` | จำนวนข้อความที่เก็บไว้ (10–500) ค่าเริ่มต้น 100 |

- ข้อความเก็บที่ `data/chat.json` (อย่าลืมเมาท์โฟลเดอร์ `data/` ถ้าใช้ Docker ไม่งั้นประวัติแชทหายเมื่อรีสตาร์ท)
- ผู้เล่นตั้งชื่อเองได้ ไม่ต้องสมัครสมาชิก จำกัดส่งไม่เกิน 1 ข้อความต่อ 1.5 วินาที และ 12 ข้อความต่อนาที
- แอดมินจัดการแชทที่หน้า `/admin.html` ส่วน "จัดการแชท": ลบข้อความ, บล็อกผู้ส่ง (ตามไอพี ที่เก็บเป็นแฮช ไม่เก็บไอพีจริง), ลบทั้งหมด
- ถ้าอยู่หลัง Nginx ต้องตั้ง `TRUST_PROXY=1` (ไม่งั้นทุกคนถูกมองเป็นไอพีเดียว จะโดนจำกัดความเร็วและบล็อกพร้อมกัน) และปิดการ buffer ของ proxy สำหรับ `/api/chat/stream` (เซิร์ฟเวอร์ส่ง `X-Accel-Buffering: no` ให้แล้ว)

## หน้าแอดมิน
ตั้ง `ADMIN_PASSWORD` ใน `.env` แล้วเปิด `/admin.html` ใส่รหัสผ่านเพื่อแก้ตารางเวลาและข้อความประกาศ (ขึ้นแถบสีเหลืองบนหน้าแรก)
- ใส่รหัสผิดเกิน 5 ครั้ง จะถูกบล็อก IP นั้น 10 นาที
- ควรเปิดผ่าน HTTPS เสมอเมื่อขึ้นเว็บจริง เพราะรหัสผ่านถูกส่งไปกับคำขอ
- ถ้าอยู่หลัง proxy ต้องตั้ง `TRUST_PROXY=1` ไม่งั้นระบบมองว่าทุกคนเป็น IP เดียวกัน

## เอฟเฟกต์เสริมธีม Minecraft
ไฟล์ `public/mc-extra.js` + `public/mc-extra.css` (ไม่ต้องตั้งค่าอะไร ไม่ยิง API เพิ่ม)
- **ป้าย Advancement Made!** เด้งมุมจอตอนเซิร์ฟเปิด / มีคนเข้าเกม / คัดลอกที่อยู่เซิร์ฟ / เปิดครบทุกแท็บ (ได้ครั้งเดียว) / มีผู้นำอันดับคนใหม่
- **เสียง Minecraft** สังเคราะห์ด้วย WebAudio (ไม่มีไฟล์เสียง): คลิกปุ่ม, level-up ตอนเซิร์ฟเปิด/มีคนเข้า, เสียงฟู่และระเบิดของครีปเปอร์ **ปิดเป็นค่าเริ่มต้น** กดปุ่มลำโพงเล็ก ๆ มุมขวาล่าง (มือถือ: ช่องที่ 8 ของ Hotbar) เพื่อเปิด จำค่าไว้ในเบราว์เซอร์
- **อันดับแบบโพเดียม** อันดับ 1-3 ตั้งบนแท่นสูงต่ำต่างกัน อันดับ 1 มีมงกุฎลอยและหัวสกินใหญ่ขึ้น เมื่ออันดับเปลี่ยนจะมีลูกศร ▲▼ และอนิเมชัน ถ้ามีผู้นำคนใหม่มงกุฎจะตกลงมาให้
- **สกินเต็มตัว** ชี้ที่ชิปผู้เล่นจะเห็นสกินเต็มตัว (จาก mc-heads) เอียงตามเมาส์ และหัวสกินหันตามเมาส์ (บนมือถือแตะที่ชิป)
- **แถบ XP** ใต้การ์ดสถานะ เติมตามจำนวนคนออนไลน์ มี orb ลอยเข้าแถบ และขึ้น level ตอนมีคนเข้าเกม
- **เคอร์เซอร์พิกเซล** (ดาบ / พิคแอ็กซ์ตอนชี้ปุ่ม) เฉพาะอุปกรณ์ที่มีเมาส์ ปิดได้ที่ปุ่มมุมขวาล่าง และ **รอยแตกของบล็อก** เมื่อคลิกพื้นที่ว่าง
- **Hotbar 9 ช่อง** ล่างจอบนมือถือ (7 ช่องเมนู + เสียง + สลับธีม)
- **Easter egg**: พิมพ์ `herobrine` หรือกด ↑↑↓↓←→←→BA หรือแตะโลโก้ 7 ครั้ง = Herobrine โผล่แวบเดียว, แตะโลโก้ = เรียกมอน, และมีหมู / เอนเดอร์แมนวาป / ค้างคาว เดินข้ามจอเป็นระยะ (คลิกมอนได้)

## มินิเกม + กระดานคะแนนกลุ่ม
แท็บ **มินิเกม** (ซ่อนอัตโนมัติถ้าตั้ง `GAMES_ENABLED=false`) โค้ดอยู่ที่ `games.js` (ฝั่งเซิร์ฟเวอร์) และ `public/mc-games.js` (ฝั่งหน้าเว็บ)
- **Creeper Dash**: แตะ/Space/↑ กระโดดข้ามกระบองเพชรและลาวา ยิ่งไกลยิ่งเร็ว
- **Whack-a-Mole**: 45 วินาที ตีซอมบี้ (+10) ซอมบี้ทอง (+25) อย่าตีหมู (−10) และครีปเปอร์ (−20)
- **ท้าทายรายวัน**: ทุกคนได้ลำดับอุปสรรค/มอนเหมือนกันตามวันที่ไทย (seed จากเซิร์ฟเวอร์) เล่นกี่ครั้งก็ได้ นับคะแนนสูงสุด
- **กระดานคะแนนกลุ่ม**: 10 อันดับ แยก "วันนี้" และ "ตลอดกาล" เก็บที่ `data/games.json` (เมาท์โฟลเดอร์ `data/` ถ้าใช้ Docker) ใครทำลายสถิติกลุ่มจะมีป้ายขึ้นบนหน้าเว็บ และแจ้ง Discord ถ้าตั้ง `DISCORD_WEBHOOK_URL`
- กันโกงเบื้องต้น: จำกัดคะแนนตามเวลาที่เล่น และส่งได้ไม่เกิน 1 ครั้งต่อ 6 วินาที/ไอพี (เก็บเป็นแฮช) แต่เบราว์เซอร์ส่งคะแนนเอง จึงกันคนตั้งใจโกงไม่ได้ ใช้แข่งกันเล่นๆ ในกลุ่ม ถ้าเจอคะแนนน่าสงสัย แอดมินลบได้ด้วย `POST /api/admin/games/remove` (ส่ง `{"game":"dash","name":"ชื่อ"}` พร้อมรหัสแอดมินแบบเดียวกับหน้า `/admin.html`)
- ตัวอย่างค่าใน `.env`: `GAMES_ENABLED=true`

## การ์ดผู้เล่น / กลางวัน-กลางคืน / ปุ่ม TNT
- **การ์ดผู้เล่นสะสม**: กดปุ่ม "การ์ด" ที่โพเดียมหรือแถวอันดับ จะเห็นสกินเต็มตัว สถิติทุกหมวดพร้อมอันดับ ความหายาก (Common ถึง Legendary คำนวณจากอันดับรวม ไม่นับจำนวนครั้งที่ตาย) และฉายาอัตโนมัติ เช่น "ราชาแร่", "นักล่ามอนสเตอร์", "ลูกครีปเปอร์ประจำเซิร์ฟ"
- **กลางวัน-กลางคืนตามเวลาไทย**: พระอาทิตย์/ดวงจันทร์เคลื่อนตามเวลา มีดาวตอนกลางคืน โทนสีรุ่งเช้า/เย็น และกลางคืนมีซอมบี้เดินแทนหมู ทดสอบได้ด้วย `mcSetHour(22)` ใน Console
- **ปุ่ม TNT**: ปุ่ม "ขอให้เปิดเซิร์ฟ" ติดชนวนแล้วระเบิดตอนกด (ยังส่งคำขอไป Discord ตามเดิม)
- Hotbar บนมือถือ: ถ้าแท็บเกิน 7 อัน ช่องที่ 7 เป็น "เมนูเพิ่มเติม" (⋯) กดแล้วเปิดแถบเมนูทั้งหมด

## นำขึ้นเป็นเว็บไซต์จริง
ต้องใช้โฮสต์ที่รันโปรเซสตลอดเวลา เพราะต้องเช็คเซิร์ฟเป็นระยะและบอทต้องออนไลน์ตลอด
- **VPS** (DigitalOcean, Vultr ฯลฯ): `npm install` แล้วรันด้วย `pm2 start server.js --name mc-status` ใส่หลัง Nginx/Caddy เพื่อทำ HTTPS แล้วตั้ง `TRUST_PROXY=1`
- **Railway / Fly.io / Render แบบเสียเงิน**: เชื่อม GitHub repo หรือใช้ `Dockerfile` ที่ให้มา แล้วใส่ค่า `.env` ในหน้า Environment ของโฮสต์ และเมาท์โฟลเดอร์ `data/` ไว้ถ้าอยากเก็บประวัติข้ามการรีสตาร์ท
- **Docker**: `docker build -t mc-status . && docker run -d -p 3000:3000 --env-file .env -v mc-data:/app/data mc-status`
- โฮสต์ฟรีที่หลับเมื่อไม่มีคนเข้า (เช่นแพ็กเกจฟรีของ Render) จะหยุดเช็คตอนหลับ ทำให้การแจ้งเตือนและกราฟไม่ต่อเนื่อง

## ข้อควรรู้
- ระบบถือว่า "ปิด" เมื่อเช็คไม่ติด 2 ครั้งติดกัน เพื่อกันสถานะกระพริบ
- เซิร์ฟที่ปิดเมื่อไม่มีคนเล่นแบบ Aternos จะตอบเป็นข้อความ offline อาจต้องตรวจเพิ่มเอง
- รายชื่อผู้เล่นขึ้นเฉพาะเมื่อเซิร์ฟส่งมา (ส่วนใหญ่ไม่เกิน 12 ชื่อ และบางปลั๊กอินซ่อนไว้) ถ้าไม่ส่งจะโชว์แค่จำนวนคน
- แพ็กเกจ `minecraft-server-util` ถูกประกาศว่าเลิกดูแลแล้ว แต่ยังใช้งานได้ ถ้าต้องการเปลี่ยนในอนาคตมี mcstatus.io เป็นทางเลือก
